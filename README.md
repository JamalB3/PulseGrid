# IoT Telemetry Analytics Platform

A production-inspired IoT telemetry platform that simulates connected devices, processes telemetry using a Bronze-Silver-Gold data architecture, and prepares analytics-ready datasets for dashboards and cloud deployment.

---

## Features

- Simulated IoT device fleet
- Bronze raw telemetry layer
- Silver validation and cleaning pipeline
- Gold analytics layer
- Python ETL pipeline
- Parquet data storage
- Data quality validation
- Duplicate detection
- Modular project architecture
